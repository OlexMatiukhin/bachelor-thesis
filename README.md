# ChaosCipher

A client-server web application for encrypting and decrypting **text, images, audio, and arbitrary files** using pseudorandom sequences generated by chaotic dynamical systems (Lorenz, Rössler, Chua, Duffing, Van der Pol, Forced Pendulum). Each system is coupled with a logistic map for key-space expansion.

---

## Supported Chaotic Systems

| System             | Key Parameters                           |
|--------------------|------------------------------------------|
| Lorenz             | logisticX, x₀, y₀, z₀                   |
| Rössler            | logisticX, x₀, y₀, z₀                   |
| Chua               | logisticX, x₀, y₀, z₀                   |
| Duffing            | logisticX, x₀, y₀, t₀                   |
| Van der Pol        | logisticX, x₀, y₀, t₀                   |
| Forced Pendulum    | logisticX, x₀, y₀, t₀                   |

## Supported Data Types

- **Text** — character-level and byte-level (SHA-based) encryption modes
- **Images** — pixel-level XOR encryption (PNG)
- **Audio** — byte-stream XOR encryption
- **Files** — streaming chunk-based encryption (64 KB chunks) for arbitrary file types

## Launch

### 1. Prerequisites

- **Python 3.10+**
- **pip**

### 2. Install dependencies

```bash
cd СhaosCipherServer
pip install -r requirements.txt
```

### 3. Start the server

```bash
cd СhaosCipherServer
uvicorn main:app --reload --port 8000
```

The server will:
- Serve the **API** at `http://localhost:8000`
- Serve the **client UI** (static files) at `http://localhost:8000/`

### 4. Open the application

Navigate to **http://localhost:8000** in your browser.

## API Endpoints

| Method | Path              | Description                  |
|--------|-------------------|------------------------------|
| GET    | `/`               | Serves the client UI         |
| POST   | `/encrypt/text`   | Encrypt text                 |
| POST   | `/decrypt/text`   | Decrypt text                 |
| POST   | `/encrypt/image`  | Encrypt an image (PNG)       |
| POST   | `/decrypt/image`  | Decrypt an image (PNG)       |
| POST   | `/encrypt/audio`  | Encrypt an audio file        |
| POST   | `/decrypt/audio`  | Decrypt an audio file        |
| POST   | `/encrypt/file`   | Encrypt a file (streaming)   |
| POST   | `/decrypt/file`   | Decrypt a file (streaming)   |

All encryption/decryption endpoints accept `system`, `params` (JSON), and `data_type` as form fields.
